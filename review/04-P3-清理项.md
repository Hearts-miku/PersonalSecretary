# P3 — 非阻断检查

- 批量处理已不在循环里改变输入日期；finally 仍无条件恢复 initialDate。若用户处理中主动换日，结束后会被改回，建议删除过时恢复逻辑或仅恢复任务自己改过的状态。
- ReportDocument 载入旧文件时应读取真实元数据，或标为未知，避免保留虚假的当前区间。
- 文件名保留 Unicode 已解决默认周/月报冲突，但不同非法字符仍可能归一成同名，自定义覆盖应有明确提示。
- MarkdownFileManager.clearAllData 仍未检查 deleteRecursively/mkdirs 返回值，应避免部分失败却提示成功。
- 新 ZIP 已包含 Room 业务 JSON，未包含 API key 是正确边界；建议加导出格式版本并做恢复演练，不把“可导出”说成“可完整恢复”。

## 发布前条件

D-2 的开发期数据库重置不是当前阻断，正式发布前仍需确定迁移及备份政策。设备 Keystore、真实取消、真机长文档性能和签名发布本轮没有验证。不能以 JVM CryptoManager 测试证明设备加密链路。
