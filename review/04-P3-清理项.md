### 剩余

- **无 Gradle wrapper** —— `gradle/` 下只有 `libs.versions.toml`。构建版本不可复现，CI 无法
  固定，也是本审计始终无法编译验证的原因。**补 wrapper 同时能解决 `6.json` 缺失和
  [P1-15](02-P1-功能与安全.md) 的验证问题**，是投入产出比最高的一项。
- **Compose BOM 版本落差** —— `composeBom = "2024.09.00"` 搭配 AGP 9.1.1 / compileSdk 36.1 /
  Kotlin 2.2.10，落后约两年。
- **release 未开启混淆压缩** —— `isMinifyEnabled = false`。
- **`.env` 机制会把 key 打进 APK** —— 发布版本建议完全依赖应用内设置的 key。
- **`kotlin.compiler.execution.strategy=in-process` 被注释掉** —— 第 3 轮的改动，未说明理由。
  该行原本用于规避「Could not connect to Kotlin compile daemon」。
- **`logging-interceptor` 仍在依赖中但未挂载** —— 保持现状，接上会把 API Key 与用户全部
  工作内容写进 logcat。
