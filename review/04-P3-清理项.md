# 非阻断与长期限制

- N-36：多数普通写入口已纳入 runWriteOperation，addRawNote 文件/DB 同锁，原先窗口已改善；启动恢复 restoreLogsFromMarkdownIfNeeded 仍没有相同边界，不应宣称所有写路径均受保护。恢复/清空竞争需另验。
- N-22：锁不等于文件与 Room 的原子事务，磁盘异常、取消和半途失败的恢复协议仍缺。
- 报告预算改为优先待处理记录并从尾部截取，解决上轮特定补录遗漏；仍不代表任意长度和任意日期数量完整覆盖，应如实展示截断。
- 原始条目解析仍用 Markdown 分隔符且 ID 正则扫描整块；输入正文包含相同分隔符或伪 ID 的健壮性需测试。ID 只作为记录身份，不作为安全边界。
- 报告自定义文件名在 ViewModel 中规范化已有改善；自定义标题解析不到区间时仍可能回退当前选择器，元数据宜标未知。
- P2-17：Markdown remember 优化不是懒渲染，真机长文性能未验证。
- P2-20：应明确告知哪些内容发送给用户配置的外部端点。
- ZIP 恢复、设备 Keystore、发布迁移/签名仍待专门验收；不沿用旧“编译从未成功”等已失效结论。
