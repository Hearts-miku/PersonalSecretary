## 🆕 N-15 `getRecentLogsContext` 用 `takeWhile`，一条超长日志会截断其后全部

**位置**：[WorkLogRepository.kt:250-266](https://github.com/Hearts-miku/PersonalSecretary/blob/47d4f26/app/src/main/java/com/example/data/repository/WorkLogRepository.kt#L250)

```kotlin
private suspend fun getRecentLogsContext(): String {
    val maxChars = 25000
    var currentChars = 0
    return logDao.getAllLogsOnce()
        .filter { it.summaryMarkdown.isNotBlank() }
        .takeWhile { log ->
            val length = log.summaryMarkdown.length + log.date.length + 6
            if (currentChars + length > maxChars) false
            else { currentChars += length; true }
        }
        .joinToString("\n\n") { "### ${it.date}\n${it.summaryMarkdown}" }
}
```

字符预算本身是 [P1-6](07-已修复与回归记录.md) 的正确修法。但 `takeWhile` **遇到第一条
超预算的记录就整体停止**：

- 日志按日期倒序，正常情况下保留的是最近的连续段——合理
- 但若最近某一天的总结特别长（例如单条 26000 字），第一次判断即为 false，**返回空字符串**，
  后面所有日志都进不了 prompt，而调用方毫无察觉

**建议**：改成累加式收集（跳过超长的单条、继续收后面的），或对单条内容也做截断。

## 🆕 N-16 清空数据后文档统计不刷新

**位置**：[SettingsScreen.kt:53-57](https://github.com/Hearts-miku/PersonalSecretary/blob/47d4f26/app/src/main/java/com/example/ui/screens/SettingsScreen.kt#L53)

```kotlin
val mdInfo by viewModel.mdInfo.collectAsState()
LaunchedEffect(Unit) { viewModel.loadMdInfo() }
```

P2-3 的修法是对的（移出主线程、改为 StateFlow）。但 `LaunchedEffect(Unit)` 只在进入组合时
加载一次，而**「清空所有数据」按钮就在同一个页面上**——用户点完清空、看到成功提示，
下方「后台 Markdown 文档系统状态」卡片仍显示清空前的字节数，直到离开页面再回来。

**建议**：`clearAllData` 成功后调用 `loadMdInfo()`，或让 `mdInfo` 跟随某个数据变更信号刷新。

## P2-20 缺少数据出境告知

用户笔记、职业档案、语义搜索的 60 条日志摘要、经历生成的近期日报、以及导入文件的内容，
都会发往第三方模型服务商。应用内没有任何隐私说明，而个人中心和简历页挂着「隐私保护」徽章
——该徽章实际只表示简历里用了占位符。

清理删除，需另想存储位置。

## N-17 🆕 AI 提炼失败后需重新选择文件

**位置**：[WorkLogViewModel.kt:281-300](https://github.com/Hearts-miku/PersonalSecretary/blob/47d4f26/app/src/main/java/com/example/ui/viewmodel/WorkLogViewModel.kt#L281)

N-7 的修法（失败时 `showSnack` + `return@launch`）方向正确。但 ProfileScreen 在点击按钮的
瞬间就执行了 `showImportTypeDialog = false; pendingImportContent = null`，所以提炼失败后
已读取的文件内容被丢弃，用户必须重新走一遍文件选择流程。

**建议**：失败时保留 `pendingImportContent`，让用户可以改选「直接导入」。
