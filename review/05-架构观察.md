# 架构与新增能力覆盖

本轮按 code-review-skill 的 Kotlin 指南检查协程取消、锁边界和状态归属，未改源码。

| 本轮新增/修改能力 | 审查结果 |
|---|---|
| AI final/partial/reasoning 分类 | parseOpenAiChatResponse 真正接入请求链，推理/截断返回失败，关闭原 N-40 代码问题 |
| RawNoteEntry / 稳定 ID / 多行处理 | ID 路径比文本猜测可靠；空快照回退仍破坏语义 |
| 统一写入屏障 | 大部分手动保存/导入/待办与清空互斥；新增测试错误地重入锁 |
| 任务取消链 | 等待取消中前任且保留任务链；跨类型 busy 归属仍需修 |
| 报告预算与说明 | 新补录优先且取末尾；覆盖说明不应由模型字符串控制 |
| 报告名规范化 | 保存/删除统一规范化，旧特殊字符预览残留风险改善 |

本轮没有新增布局文件差异；并不意味着上轮 UI 已通过真机验收。所有 7 个变更文件（4 个生产文件、3 个测试文件）均纳入审查。

建议把“没有待处理记录”“最终结果完整”“任务已结束”“清空已提交”建模成显式状态，不靠空集合回退、文本关键词或若干独立布尔值推断。
