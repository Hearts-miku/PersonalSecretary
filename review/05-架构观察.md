# 架构观察

按照 code-review-skill 的 Kotlin 指南，重点检查了取消完成语义、共享状态归属和存储一致性；未修改源码。

## 已有进展

AI 可以注入，Repository 层已有假 AI 回归测试；原始笔记不再被摘要替代；总结提交引入互斥和清空代际；待办合并避免直接抹掉旧任务；临时文件写入有实例内锁。

## 剩余边界

1. 原始事实历史与待处理队列仍共用 rawNotes，导致报告预算与临时文件清理无法准确知道哪条记录是新输入。需要 ID/批次/处理游标，而非进一步堆叠字符串匹配。
2. 清空代际只在一个业务流程实施，不是整个 Repository 的写入契约。
3. cancel 请求、任务结束、UI busy 状态是不同事件；串行化切换和身份验证应覆盖收尾。
4. AI 成功状态应表达最终结果完整性，而不是“任意字段里有文本”。推理草稿和部分输出不能无条件驱动持久化。

本轮 UI 改版和导航入口已静态检查，未进行屏幕布局/触控/无障碍验收。
