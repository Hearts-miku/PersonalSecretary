## 批次 2 — 升级路径的两个风险

| 编号 | 内容 |
|---|---|
| [N-5](02-P1-功能与安全.md) | 存量明文 API Key 会被 Base64 解码损坏。加版本前缀（存 `v1:<base64>`，只对带前缀的解码）或写一次性迁移 |
| [P1-4](02-P1-功能与安全.md) | `CryptoManager` 改用 `EncryptedSharedPreferences` 或 Keystore + AES/GCM。若暂不做真加密，**至少把类名/方法名改成 `encode`/`decode`** 并注明不提供机密性 |

两者一起做最省事——反正都要动 Key 的存储格式。

**验收**：一条测试覆盖「明文输入经 decrypt 后不变」，一条覆盖「encrypt→decrypt 往返一致」。
