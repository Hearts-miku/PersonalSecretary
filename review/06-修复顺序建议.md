### D-1 删除 Gemini / Anthropic 两条 API 路径

产品方向确定：只保留自定义 OpenAI 兼容 provider。完整清理清单见
[04-P3-清理项.md](04-P3-清理项.md) 第 2 节。

**执行时的两个注意点**：

1. **不要连带删掉仍然有用的保护**。三家 provider 的截断检测是同一批工作的产物，
   其中 **OpenAI 的 `finish_reason == "length"` 必须保留**；o1/o3 的 `temperature`
   保护同样保留。只删 Gemini 与 Anthropic 的对应分支。
2. **`apiProvider` 字段的删除是 schema 变更**。因应用未发布，可直接重新生成 `6.json`
   而不必新增 6→7 迁移——与下面 D-2 一起决定。

### D-2 待确认：`MIGRATION_5_6` 的去留

应用未发布，外界不存在 v5 数据库，这段迁移只对开发机有意义。可选：

- (a) 保留 —— 开发机上的测试数据能平滑升级
- (b) 删除并重置数据库版本 —— 不再维护一段没有真实用户会走到的代码

选哪个取决于开发机上是否有需要保留的测试数据。与 D-1 的 `apiProvider` 字段删除一起做
最省事。
