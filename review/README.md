### 本轮进展

**`app/schemas/6.json` 已生成并提交。** 它与
[实体定义](https://github.com/Hearts-miku/PersonalSecretary/blob/7679b62/app/src/main/java/com/example/data/local/Entities.kt)、以及
[`MIGRATION_5_6`](https://github.com/Hearts-miku/PersonalSecretary/blob/7679b62/app/src/main/java/com/example/data/local/AppDatabase.kt#L30)
的建表语句三者逐列一致——说明项目**确实被构建过了**，schema 不匹配的风险已消除。
这是 [P1-15](03-P2-健壮性与体验.md) 得以降级的另一半原因。

**产品方向收敛为单一自定义 provider。** 多服务商选择器从设置页移除，
`apiProvider` 固定写入 `"CUSTOM"`。这是明确的产品决策，相应的清理工作已记录为
[D-1](06-修复顺序建议.md)。

### 需要在发布前处理

[P1-17](02-P1-功能与安全.md)：占位域名 `api.your-provider.com` 成了**功能性默认值**——
新装用户填入 API Key 后，凭据会被发往这个不受项目控制的域名。这是当前唯一的
发布阻断级问题。
