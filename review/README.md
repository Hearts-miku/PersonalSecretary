### 本轮以新功能为主

两个提交 `d8cedda`（AI 连接测试 + 日期导航）与 `e543020`（按项目维度提炼待办）
增加了三项功能，上一轮修复计划中的批次 1（取消机制收口）未动。

**新功能本身的完成度不错**：

- **连接测试**测的是尚未保存的输入值，显示耗时与响应片段；新增的 4 个 `testConnection`
  用例真正调用了生产代码，且只走校验失败分支，不发网络请求
- **日期导航**在 Home 页清晰显示「记录日期」，有今天 / 昨天快捷切换，未来日期在
  `selectDate` 中被钳制为今天——补记旧日期是一项信息清晰的有意设计
- **按项目提炼待办**的 prompt 结构清楚；待办页的项目筛选 chip 由 category 动态生成，
  并排除「工作」「通用项目」等泛称

`Entities.kt` 本轮只给 `DailyWorkLogEntity` 加了 Kotlin 默认值，不涉及 schema，
`7.json` 仍与实体一致。
